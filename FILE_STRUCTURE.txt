GETTING STARTED
═══════════════════════════════════════════════════════════════════════════════

1. READ: 00_START_HERE.md
   └─ 10 minute overview of what you have

2. COPY: ha_rtt_integration/custom_components/realtime_trains_api_ng/
   └─ To: ~/.homeassistant/custom_components/

3. RESTART: Home Assistant
   └─ Settings → System → Restart

4. CONFIGURE: Settings → Devices & Services → Create Integration
   └─ Search "Realtime Trains API (Next Generation)"

5. SETUP: Enter Bearer token + station codes
   └─ Get token from: https://api-portal.rtt.io/

6. VERIFY: Check sensor appears
   └─ Developer Tools → States → search "sensor.next_train"

RTT_API.PY (320 lines)
├─ class RttApi:
│  ├─ __init__(token)           - Initialize with Bearer token
│  ├─ search_departures()       - Get trains leaving a station
│  ├─ search_arrivals()         - Get trains arriving at a station
│  ├─ fetch_service_details()   - Get detailed train info
│  └─ get_api_info()            - Check API status
└─ All HTTP requests with error handling

__INIT__.PY (180 lines)
├─ async_setup_entry()          - Called when integration loads
├─ async_unload_entry()         - Called when unloading
└─ RttDataUpdateCoordinator:
   └─ _async_update_data()      - Fetches data every 90 seconds

CONFIG_FLOW.PY (95 lines)
├─ RttConfigFlow class:
│  ├─ async_step_user()         - Get Bearer token
│  └─ async_step_queries()      - Configure stations
└─ Handles setup UI

SENSOR.PY (300 lines)
├─ async_setup_entry()          - Create sensors
└─ RttTrainSensor class:
   ├─ native_value              - State: minutes until train
   └─ extra_state_attributes    - Full train details

USAGE IN HOME ASSISTANT
═══════════════════════════════════════════════════════════════════════════════

Automation - Alert before train:
  trigger:
    platform: numeric_state
    entity_id: sensor.next_train_from_lds_to_kgx
    below: 5

Template Sensor - Show operator:
  state: >
    {{ state_attr('sensor.next_train_from_lds_to_kgx', 'next_trains')[0]['operator'] }}

Script - Get departure time:
  variables:
    departure: >
      {{ state_attr('sensor.next_train_from_lds_to_kgx', 'next_trains')[0]['estimated_departure'] }}
